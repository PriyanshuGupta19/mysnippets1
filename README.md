# HTML and JavaScript Snippets Extension

## Overview
This VS Code extension provides a collection of useful HTML and JavaScript code snippets to boost your development productivity.

## Features
- Quick HTML markup snippets
- Common JavaScript function templates
- Efficient web development shortcuts

## Installation
1. Open Visual Studio Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "myOwnSnippets"
4. Click Install
